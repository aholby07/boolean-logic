# 4-Bit Adder
A 4-bit adder, as the name suggests, is a circuit that focuses on and handles addition. Specifically, it is made to handle the addition of two 4-bit binary numbers.

# 1:4 Demultiplexer
A 1:4 demultiplexer is a circuit that can take a single data input and distribute it across 4 different possible outputs. By using two select lines, you can determine which paths and outputs the data is directed through.
